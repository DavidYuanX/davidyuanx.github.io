Flutter 优化

  • 使用 const 构造函数
  • 避免在 build 方法中创建对象
  • 使用 ListView.builder 代替 ListView
  • 图片使用 cached_network_image

Spring Boot 优化

  • 使用 WebFlux 响应式编程
  • Redis 缓存热点数据
  • 数据库连接池优化
  • 异步处理耗时操作
